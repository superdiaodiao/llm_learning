# 第二个合集：动手用大模型（课表）

> 状态：规划稿，未开写。主线合集「从零看懂大模型」讲**看懂**；这个合集讲**上手**。两个合集各自编号、各自成线，互相引用。

## 定位

- **读者**：已经在用 ChatGPT / Claude / 豆包 / Cursor / Claude Code 之类工具的人，想让它更听话、更省事，不想学编程。
- **要解决的问题**：网上这块内容要么是"照这个模板抄"，要么是某个工具的操作手册。前者不知道为什么，换个场景就不会了；后者半年就过时。
- **写法原则**：每课讲一条**跨工具的原理**，配**一个工具里的一个例子**（标明"以 X 为例"）。原理来自主线课，例子可以换。工具的文件名、目录、按钮位置，一律放在例子里，不进原理。

## 一条主线贯穿

**这些东西的读者是模型，不是人。** 它每轮都从头读、读完就忘、窗口有限、开头结尾记得牢中间容易丢、能用代码保证的别靠它自觉。主线第 5 课（上下文窗口）和仓库 11 篇（harness）已经把原理立住了，这个合集只做一件事：把原理翻译成写法和用法。

## 课程表

分四层，由"每次都要做的"到"做一次长期用的"到"打包复用的"到"外接和验证"。

### 第一层 · 对话（每次都在做的事）

| # | 标题（钩子） | 你学会 | 挂主线 |
|---|---|---|---|
| 1 | 跟 AI 说话，为什么不能像跟人说话 | 它每轮从头读、读完就忘、窗口有限 → 三条：别让它猜、要求放头尾、每个字都占地方。例子：同一条"帮我改一下这段"改写三次 | 第 5 课 |
| 2 | 让 AI 一次做对：一条要求的四个部件 | 任务、材料、格式、例子；要求放头尾，材料放中间；给一个样例胜过十句形容。例子：一句话"写个周报"扩成四部件版 | 第 3、5 课 |
| 3 | AI 的深度思考按钮，什么时候该开 | 普通模型 vs 推理模型；多步推理、算数、找错要开，闲聊、翻译、改文案别开（慢且贵）。例子：同一道题开关各跑一次 | 推理课（主线待写） |
| 4 | AI 一本正经地编，三招治它 | 给材料、要它标出处、允许它说不知道；哪些问题天生不该问它（冷门事实、精确数字、最新消息）。例子：问一本不存在的书 | 第 4 课 |

### 第二层 · 规则（写一次，长期生效）

| # | 标题（钩子） | 你学会 | 挂主线 |

| 7 | 让 AI 记住你：规则、记忆、每次说 | 稳定的进规则，会变的进记忆，一次性的每次说；记忆是怎么存的、为什么会记错 | 仓库 07 |

## 和主线的关系

- 主线不停，两条线交替发。实操课短（800–1200 字），可以补主线的间隔。
- 实操课不重讲原理，一句话带过并链接主线对应课。主线读者是"想看懂的人"，实操读者是"想上手的人"，两个合集互相导流。
- 仓库侧对应：11 篇已有 MCP / hook / 评测的原理；规则文件和 skill 写法需要补一篇 `12 · 写给 Agent 看的文档`（中英）。实操课 5–11 从 12 篇改写。

## 顺序

先写 1 → 5 → 8 → 9（每层的第一课），验证这个合集有没有人看，再补齐各层。第 1 课可以先于仓库 12 篇出，它只依赖主线第 5 课。

## 不写什么

- 某个工具的按钮在哪、菜单怎么点。
- 没有稳定定义的新词。
- "用某种语气能省 token"这类没有可迁移原理的技巧。
- 编程本身。读者写 skill 用的是自然语言，脚本部分让 AI 自己写。

## 运营约定

- 每个标题都带 AI，信息流里光看标题就知道是什么。
- 标题一律不带编号：这个合集每课独立成篇，顺序弱，不需要门槛。眉标写「动手用大模型 · 第 N 课」。
- 封面沿用同一套版式，强调色换蓝（主线是红），让读者在信息流里一眼分得出两条线。
- 例子前四课统一「以 Claude Code 为例」，其他工具一句话带过，避免每课都在讲三套目录。
- 文末固定一行「原理见《从零看懂大模型》第 N 课」，两个合集互相导流。
- 两条线交替发：一周主线，一周实操。实操课 800–1200 字。
- 先发 1 → 5 → 8 → 9，看数据再补齐各层。
